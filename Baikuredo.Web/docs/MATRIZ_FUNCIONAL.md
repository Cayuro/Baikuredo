# Matriz Funcional — Baikuredo

| Código | Nombre | Actor | Descripción |
| :--- | :--- | :--- | :--- |
| F001 | Consultar motocicletas disponibles | Cliente / Visitante | El cliente puede visualizar las motocicletas que cuentan con publicaciones activas disponibles para la venta. |
| F002 | Consultar detalle de motocicleta | Cliente / Visitante | El cliente puede consultar información detallada del vehículo, precio de venta, estado de la publicación e imágenes asociadas. |
| F003 | Registrar interés sobre publicación | Cliente / Visitante | El cliente puede enviar una solicitud de información directa relacionada con una publicación específica. |
| F004 | Inicio de sesión | Administrador | El usuario administrador ingresa sus credenciales de acceso para autenticarse e ingresar al sistema. |
| F005 | Registrar propietario | Administrador | El administrador registra propietarios que pueden vincularse a una o varias motos, evitando redundancia. |
| F006 | Registrar motocicleta | Administrador | Registra una moto asociando modelo, propietario y registrando el usuario administrativo responsable. |
| F007 | Crear publicación de venta | Administrador | Crea publicaciones asociadas a una motocicleta existente registrando precio, estado, fecha y usuario responsable. |
| F008 | Consultar historial de publicaciones | Administrador | Consulta publicaciones previas de un vehículo sin necesidad de duplicar el registro básico de la moto. |
| F009 | Registrar imágenes | Administrador | Asocia una o múltiples imágenes a una motocicleta registrada para su posterior visualización gráfica. |
| F010 | Registrar marca y modelo | Administrador | Gestiona la información de parametrización necesaria para clasificar correctamente las motocicletas. |
| F011 | Consultar interesados | Administrador | Permite al administrador consultar el listado de personas interesadas en una publicación específica. |
